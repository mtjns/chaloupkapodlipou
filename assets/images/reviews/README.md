# Reviewer profile pictures

Drop guest profile pictures here and reference them from `_data/reviews.yml`
via the `photo` field, e.g. `photo: "/assets/images/reviews/jana-novakova.jpg"`.

- Square images work best (e.g. 200×200). They are shown as small avatars.
- `.jpg`, `.png`, or `.webp` are all fine.
- Leave `photo: ""` in `reviews.yml` to fall back to an initials avatar.
